# 🍽️ Swiggy SQL Data Analysis Project

## 📌 Project Overview

This project was created to strengthen my skills in **Microsoft SQL Server Management Studio (SSMS)** and SQL by working with a real-world food delivery dataset. The project covers the complete data analysis process—from data cleaning and database design to analytical queries that generate business insights.

Rather than focusing only on writing SQL queries, I explored how data is prepared, structured, and analysed within a relational database.

---

## 🎯 Objectives

* Practice using Microsoft SQL Server Management Studio (SSMS)
* Clean and validate raw data
* Identify and remove duplicate records
* Design a relational database using a star schema
* Create dimension and fact tables
* Establish relationships using primary and foreign keys
* Answer business questions using SQL

---

## 🛠️ Technologies Used

* Microsoft SQL Server Management Studio (SSMS)
* SQL Server
* T-SQL

---

## 📂 Database Design

The project consists of:

### Fact Table

* Fact_Swiggy_Orders

### Dimension Tables

* Dim_Date
* Dim_Restaurant
* Dim_Dish
* Dim_Category
* Dim_Location

This star schema improves data organisation and supports efficient reporting and analysis.

## 🚧 Challenges Faced

Throughout this project I encountered several challenges:

* Understanding how to design a proper star schema instead of keeping everything in one table.
* Learning the difference between fact and dimension tables.
* Creating relationships using primary and foreign keys.
* Debugging joins that returned incorrect results due to duplicate or unmatched records.
* Organising SQL scripts into a logical ETL process before performing analysis.

These challenges improved my understanding of relational databases and strengthened my SQL problem-solving skills.
